# 学生成绩统计程序（score_statistics）

一个用 Python 编写的命令行小工具：逐个录入 0-100 分的成绩，自动换算成 A/B/C/D/F 等级，
输入 `q` 结束录入。程序会校验输入是否合法，遇到非数字或超出范围的分数会提示并让用户重新输入。

## 项目简介

批改作业或登记成绩时，手工把分数换算成等级既慢又容易出错。这个小程序解决三个问题：

- **换算自动化**：按"90 分以上 A、80 分以上 B、70 分以上 C、60 分以上 D、其余 F"的规则即时给出等级；
- **输入容错**：非数字、越界分数不会让程序崩溃，只会打印提示并继续等待输入；
- **交互友好**：通过 `q`（大小写均可）随时退出，适合在终端里边想边敲。

## 运行环境

- Python 3.6 及以上（代码中使用了 f-string 格式化）
- 无第三方依赖，只用标准库

## 使用方法

```bash
python score_statistics.py
```

## 代码说明

### 1. 等级换算：`grade_of(score)`

把分数映射成等级的纯函数，用 `if/elif/else` 从高到低依次判断，第一个满足条件的分支返回结果，
因此不会出现区间重叠或遗漏：

```python
def grade_of(score):
    if score >= 90:
        return "A"
    elif score >= 80:
        return "B"
    elif score >= 70:
        return "C"
    elif score >= 60:
        return "D"
    else:
        return "F"
```

把它单独写成函数，而不塞进输入循环里，好处是换算规则只有一处、便于测试和修改
（例如把 90 分改成 85 分，只需改一行）。

### 2. 输入循环与退出：`main()`

主逻辑是一个 `while True` 循环，每次读入一行、去掉首尾空白，再判断是否退出：

```python
while True:
    text = input("成绩：").strip()
    if text.lower() == "q":
        break
```

`.strip()` 让 `" 90 "` 和 `"q "` 也能被正确识别；`.lower()` 让 `Q` 和 `q` 等价。

### 3. 输入校验：用 `try/except` + 范围判断

程序分两层把关：先看能不能转成数字，再看是否落在 0-100 之间。转换失败时用 `continue`
跳过本轮、重新询问，而不是让 `ValueError` 直接终止程序：

```python
try:
    score = float(text)
except ValueError:
    print("请输入 0-100 的数字，或输入 q 结束。")
    continue
if not 0 <= score <= 100:
    print("成绩必须在 0 到 100 之间。")
    continue
```

这里用 `float` 而不是 `int`，是为了支持 85.5 这类带小数的成绩。

### 4. 输出格式化

```python
print(f"{score:g} 分 -> {grade_of(score)} 等级")
```

`{score:g}` 会去掉多余的小数部分：`85.0` 显示成 `85`，`72.5` 保持 `72.5`，输出更自然。

### 5. 程序入口

```python
if __name__ == "__main__":
    main()
```

这是 Python 的惯例写法：只有直接运行脚本时才执行 `main()`；被别的文件 `import` 时只导入
`grade_of()` 等函数，不会自动开始读输入，方便复用和测试。
